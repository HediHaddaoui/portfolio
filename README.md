## 🌟 Présentation

Bienvenue sur le dépôt officiel de mon portfolio d'ingénieur. Ce site met en valeur mes compétences en :
- **IoT & Systèmes Connectés** : ESP32, Arduino, STM32, Raspberry Pi, protocoles MQTT, Node-RED.
- **Réseaux & Systèmes** : Certification CCNA (Cisco), TCP/IP, Wi-Fi, Linux, Git / GitHub.
- **Développement Logiciel & Mobile** : Python, Java, C/C++, Flutter (Dart), Firebase, TypeScript / Next.js.
- **Cloud & DevOps** : AWS, Microsoft Azure, Docker, CI/CD.
- **Conception Électronique** : Schémas et routage de cartes PCB sous KiCad / Eagle.

---

## 🚀 Projets Clés Présentés

1. **Supervision du Transport Public** : Application mobile Flutter & Firebase pour le suivi en temps réel des lignes de bus et l'information des voyageurs en Tunisie.
2. **Smart Farm (Agriculture Connectée)** : Plateforme IoT à base d'ESP32 et de capteurs de sol/air avec télémétrie MQTT et tableau de bord temps réel sous Node-RED.
3. **Smart Home (Contrôle Domotique)** : Pilotage à distance et supervision d'équipements électriques via relais industriels et microcontrôleur ESP32.
4. **Robot Détecteur d'Incendie & PCB** : Système autonome de sécurité avec conception et routage complet du circuit imprimé (PCB) double couche sous KiCad.

## 🛠️ Stack Technique du Portfolio

- **Framework** : [Next.js](https://nextjs.org/) (App Router & Turbopack)
- **Langage** : [TypeScript](https://www.typescriptlang.org/)
- **Style** : [Tailwind CSS](https://tailwindcss.com/) & Design System personnalisé (Dark/Light mode)
- **Animations** : [Framer Motion](https://www.framer.com/motion/)
- **Icônes** : [Lucide React](https://lucide.dev/)

## 💻 Démarrage en local

```bash
# Cloner le dépôt
git clone https://github.com/HediHaddaoui/portfolio.git

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

Rendez-vous sur [http://localhost:3000](http://localhost:3000).
